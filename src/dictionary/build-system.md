# 术语字典：构建系统 (Build System)

在 Rust 的世界里，构建系统的术语充满了浓厚的“工业物流”隐喻。理解这些隐喻，能帮你更好地理解工具的设计初衷。

## 1. Cargo

- **全称**: Cargo
- **词源**: 英语单词，意为“货物”、“船货”。
- **含义**: Rust 的包管理器和构建工具。
- **哲学**: 既然代码是要被交付的“产品”，那么管理这些产品的工具自然就是“负责装运货物的系统”。Cargo 负责下载依赖、编译代码、打包分发，就像港口的物流系统一样处理所有的货物调度。

## 2. Crate

- **全称**: Crate
- **词源**: 英语单词，意为“板条箱”（通常用于装运水果或大型机器的透气木箱）。
- **含义**: Rust 中的编译单元。它可以是一个二进制文件 (Binary Crate)，也可以是一个库 (Library Crate)。
- **哲学**:
    - **独立性**: 每个箱子都是独立的，里面装着完整的货物（代码）。
    - **可组合性**: 多个箱子可以堆叠在一起运输。
    - **对比**: 其他语言可能叫 Package (包裹) 或 Module (模块)。Rust 叫 Crate，强调了它是 Cargo 系统中被运输和管理的最小实体单位。

## 3. Toml

- **全称**: Tom's Obvious, Minimal Language
- **词源**: 发明者 Tom Preston-Werner (GitHub 联合创始人) 的名字 + 显而易见 (Obvious) + 极简 (Minimal)。
- **含义**: Rust 项目的配置文件格式 (如 `Cargo.toml`)。
- **哲学**:
    - **人类可读**: 相比 JSON 的花括号地狱和 YAML 的缩进地狱，TOML 旨在提供最清晰的键值对阅读体验。
    - **确定性**: 它的语法设计非常严格，减少了歧义。

## 4. Manifest

- **全称**: Manifest
- **词源**: 航运术语，“载货清单”或“舱单”。
- **含义**: 指 `Cargo.toml` 文件。
- **哲学**: 既然是 Cargo (货物) 系统，那么说明货物内容的清单自然就是 Manifest (舱单)。它列出了这艘船（项目）上装了哪些 Crate (箱子/依赖)，以及货物的基本信息（版本、作者）。

## 5. Registry

- **全称**: Registry
- **词源**: 注册处、登记处。
- **含义**: 托管 Crates 的中心仓库（默认是 crates.io）。
- **哲学**: 就像船舶在港口需要在海关登记一样，所有的开源 Crate 都在 Registry 中登记造册，供全世界的开发者检索和下载。
